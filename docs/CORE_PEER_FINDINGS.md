# 買取再販・企業横断調査：全15グループを維持した初回実証

**調査固定範囲：15企業グループ／登録証券コード16／中核6、比較9。**
[15社×3年の進捗マトリクス](COHORT_COVERAGE.md)、
[全企業の一次資料入口](../config/primary_source_index.csv)を参照。
**2社・4社の分析だけで15社の結論を出してはならない。**

## 中核6社すべてについて原資料の数値を登録（ただし企業別検証精度は異なる）

- 2024〜2026年の比較対象6グループに財務資料の一部を登録済み。
- 全社で完全な3年比較ができる段階ではなく、東京中古マンションに限った在庫も未確定。

## 仮説の暫定的な検証結果

**東京都REINSの売出在庫増・成約減だけから、買取再販業者15社が一斉に出口渋滞を起こしたとは言えない。**

一方、ランドネットの販売用不動産＋30.9%、短期借入金＋57.1%、利払い＋49.6%と、ムゲンエステートの営業CFマイナス転換は、資金コスト・回収負担を疑う具体的な観測点である。ただしどちらも仕入規模拡大によって説明できる可能性があり、売却期間・価格改定履歴・中古区分マンションの地理的内訳が必要。

**最大の新論点は在庫の中身である。** ムゲンエステートでは増えた在庫の大部分が投資用不動産だった。混合在庫の増加を「東京中古マンションの滞留」と誤読すれば、研究の核心を取り違える。

会社・年度・連結／単体・保有目的の区分を保持して分析する。公式提出書類に基づくが、転記元のクロスチェックは全件完了していないため、発表稿ではない。
