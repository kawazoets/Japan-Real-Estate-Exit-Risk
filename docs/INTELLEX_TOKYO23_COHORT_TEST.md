# 東京23区の買取再販を、会社の仕入・販売単価まで絞って検証

2026-11-17付研究ノート。東京中古マンション買取再販業者に出口渋滞が起きたかが主眼。調査対象15社（重点候補3・条件付き3・比較9）は固定。

> **2026年10月9日公表資料との照合差分（追記）**：このノートで記録した**2026年5月期1Q東京23区仕入70件**は、2025年10月6日公表の旧インテリックス資料p.42に基づく数値です。新会社インテリックスHDの2026年10月9日資料p.48では、同四半期の比較値が**69件**に変更されています。理由は未確認。数字を無断で置き換えず、[両社公式資料の不一致と2027年5月期1Qの続報](INTELLEX_TOKYO23_2027Q1_CHECK.md)を参照してください。

## 1. インテリックス：東京23区の仕入・販売を一次資料で確認

[2025年10月6日公表の2026年5月期第1四半期公式決算説明資料](https://www.intellex-hd.co.jp/ir/library/explanation/archive/pdf/financial_results/20251006.pdf)、PDF **p.40（販売）・p.42（仕入）**。期間は**2025年6月～8月の第1四半期**と前年同期。**2026年10月のREINS市場統計と同時期ではない**。

| 東京23区のリノヴェックスマンション | 2025年5月期1Q | 2026年5月期1Q | 変化 |
|---|---:|---:|---:|
| 仕入件数 | 65 | 70 | +7.7% |
| 平均仕入価格 | 3,100万円 | 5,500万円 | +77.4% |
| 仕入総額の概算（件数×開示平均） | 約20.15億円 | 約38.50億円 | **+91.1%** |
| 販売件数 | 44 | 52 | +18.2% |
| 平均販売価格 | 4,000万円 | 5,400万円 | +35.0% |
| 販売総額の概算（件数×開示平均） | 約17.60億円 | 約28.08億円 | +59.5% |

**件数が増えたうえ、仕入単価が非常に大きく上昇している。** 東京23区の仕入れに投入される資金は、平均価格の丸めを含む概算ながら、前年同期の約1.9倍。しかし**販売件数も増加しており、この四半期から売れ残り増加を立証することはできない**。

**仕入平均価格5,500万円と同時期の販売平均価格5,400万円を差し引いて赤字と判定してはいけない。** 仕入戸数と販売戸数は別々の物件集団で、仕入物件が後の期に販売されることもある。単価は100万円単位に丸められており、工事費、諸費用も含まない。

東京23区に偏った仕入れが、後続四半期の販売期間・粗利益にどう影響したかは未解決。この価格上昇は、仕入れ物件の立地・広さ・築年・グレードなどの構成変化も含む。

## 2. 通期の東京23区件数：二次資料の段階

- 2025年5月期：23区仕入**264件**、販売**227件**。[フィスコ企業分析（2025年9月）](https://www.fisco.co.jp/wordpress/wp-content/uploads/FISCO/intellex20250901.pdf)。
- 2026年5月期：23区仕入**305件**、販売**263件**。[フィスコ企業分析（2026年9月）](https://minkabu.jp/news/4618721)。

通期の仕入・販売とも増加している。**これは単年の新規仕入と引渡のフローであり、期末未契約在庫や売却期限経過件数ではない**。この通期数値は現時点ではフィスコ経由の二次確認であり、正式稿では2026年5月期の会社原本表に遡る。

## 3. 2026年10月の市場低迷と時点を混同しない

2026年10月のREINSでは、東京都区部の成約件数前年同月比**-26.9%**、成約㎡単価**-4.0%**。2025年6～8月に仕入れた物件が2026年10月の売出在庫にどれだけ残っているかは分からない。市場の2026年10月と会社の2025年8月終了の四半期を因果的に接続したことにはしない。

一方、[スター・マイカの2026年6～8月販売中リノベ中古区分マンション](PRICE_SEGMENT_EXIT_TEST.md)では、1億円以上の成約率が前年17%→9%（会社全域）。**これは市場の2026年秋に近い時点の企業販売指標**であるが、東京都単独ではない。

## 4. 次に必要な決定的検証

東京23区の仕入価格上昇と売却価格・粗利の差を、同じ仕入コホートで追跡すること。少なくとも**2026年5月期の第2四半期～通期、2027年5月期第1四半期**の23区別の購入・販売件数と平均価格、販売所要期間を取得し、2026年の市場成約減に対応する物件群を特定すること。

それが見つからなければ、公開資料から確認できるのは「仕入金額に見られる資金需要の増大」までであり、**東京23区の実際の滞留日数や投げ売り・価格改定による損失は未確認**と記録する。

根拠データ：[intellex_tokyo23_purchases_sales.csv](../data/processed/intellex_tokyo23_purchases_sales.csv)。この成果は東京中古マンション市場の需要だけでなく、**業者自身の東京23区物件売買**に関する確認である。
