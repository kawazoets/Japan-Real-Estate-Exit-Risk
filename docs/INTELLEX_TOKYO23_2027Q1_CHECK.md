# 東京中古マンション買取再販の出口：インテリックス 2027年5月期1Q（2026年6～8月）

**2026年11月17日検証。研究対象15社は不変。主眼＝東京中古マンションの買取再販業者の出口渋滞が実在するか、どの価格帯・経路を通じて成約価格へ波及するか。**

## 1. 新しい会社決算説明資料の東京23区、直近2四半期同月比較

一次資料：[インテリックスHD 2027年5月期第1四半期決算説明資料（2026年10月9日、TDnet提出PDF）](https://assets.minkabu.jp/news/article_media_content/urn:newsml:tdnet.info:20261008548043/140120261008548043.pdf)。原本の**印字p.46（PDF p.46）**は販売、**印字p.48（PDF p.48）**は仕入。

| リノヴェックスマンション東京23区 | 2026/5期1Q（2025年6～8月） | 2027/5期1Q（2026年6～8月） | 変化 |
|---|---:|---:|---:|
| 仕入件数 | **69件（新資料の前年値）** | **68件** | -1.4% |
| 仕入平均価格 | 5,500万円 | 6,100万円 | +10.9% |
| 仕入総額の概算 | 37.95億円 | 41.48億円 | +9.3% |
| 販売件数 | 52件 | **56件** | +7.7% |
| 販売平均価格 | 5,400万円 | **7,000万円** | +29.6% |
| 販売総額の概算 | 28.08億円 | 39.20億円 | +39.6% |

※総額概算は**件数×百万円単位へ丸めた平均単価**から算出したもの。仕入コホートと販売コホートは別物で、価格差は粗利益ではない。

東京23区の**販売件数が減っていない**ので、少なくともこの期の**決済済み販売件数だけから「出口渋滞」を立証することは不可能**。東京市場REINSの成約減少がすべての買取再販業者に等しく生じたという仮説には反証となる。他方、2026年10月市況の直接比較ではない（会社の6～8月の実績）。未売却在庫の保有日数は不明。

## 2. 東京23区の仕入れ実績、会社公式資料どうしで1件食い違う

**重要な監査記録。** 2025年10月6日発表の[旧会社インテリックス 2026年5月期1Q説明資料](https://www.intellex-hd.co.jp/ir/library/explanation/archive/pdf/financial_results/20251006.pdf) の印字p.42では、**2026/5期1Qの東京23区仕入は70件**。一方、2026年10月9日公表の**インテリックスHD 2027/5期1Q資料の前年同期比較**（印字p.48）では**69件**。後者の同表は全地域仕入257件（前者は258件）。両方とも発行会社の決算説明資料であり、元資料の変更・集計範囲変更・遡及再分類・誤記などの理由は**未確認**。

**この研究ではどちらかを勝手に正しいと断定したり上書きしたりしない。** 当年比較は新しい説明資料の「69→68件（-1.4%）」を出典別に表記し、前回研究ノートは「70件」の旧資料値として残す。取材/正式稿では会社への照会か訂正説明の有無を確認すること。

## 3. 会社全地域の事業期間と実現利益率は小幅悪化

同社[同資料p.17](https://assets.minkabu.jp/news/article_media_content/urn:newsml:tdnet.info:20261008548043/140120261008548043.pdf)、リノヴェックスマンション：

- 2026/5期下期：販売期間**110日**、施工期間**63日**、事業期間**173日**、粗利益率**13.0%**
- 2027/5期1Q：販売期間**112日**、施工期間**60日**、事業期間**172日**、粗利益率**12.0%**
- 前年同期の2026/5期1Q：販売期間**109日**、施工期間**58日**、粗利益率**13.4%**（新資料p.17の上期区分は四半期ではなく2026/5期**上期**である点に注意）

**留保：** 粗利益率はリノヴェックスマンション事業の指標で、東京都23区専用の利益率ではない。販売所要期間は**すでに販売決済した案件**の平均で、未売却の滞留期間とは異なる。販売期間が110→112日とやや長くなったが、2日の変化を「出口渋滞」の証拠にしない。粗利益率低下の原因もまだ未分離。

同じ資料の印字p.44ではリノベーション分野の**物件販売粗利益率**が前年1Q**13.9%→12.0%**である。上記p.17の時系列の各点と混ぜず、特にp.17の**13.4%は2026/5期上期全体**と表記する。

## 4. さらに重要：会社全体の不動産在庫を「東京で売れ残った住宅」と読まない

同資料p.7（2026年5月末→2026年8月末）：

| 連結 | 前期末 | 2026年8月末 |
|---|---:|---:|
| 販売用不動産 | 374.12億円 | **411.50億円** |
| 通常物件の販売用不動産 | 約259億円・551件 | **265億円・580件** |
| 賃貸物件（リースバック等） | 約112億円・235件 | **140億円・180件** |
| 有利子負債 | 約437億円 | **491億円** |
| 現金・預金 | 62.20億円 | **50.33億円** |

通常物件は+29件、賃貸物件は**-55件**。両者を混ぜると保有件数は**786→760件と減る**。一方、簿価は増加する。**物件の価格上昇・商品構成変化と保有件数の増減を区別することが重要**。

**在庫金額増+37.38億円・借入残高増+54億円・現預金減約11.87億円**は運転資金圧力の観察点。ただし長期保有収益物件の投資・リースバック資産流動化もあり、「東京23区の未契約中古マンション売れ残りによる資金繰り悪化」と断定できない。

## 5. 現時点での仮説の位置づけ

市場側：REINSの東京都区部は2026年10月、成約件数前年比-26.9%、成約平均㎡単価-4.0%、売出在庫増。**しかしこの企業の2026年6～8月東京23区販売件数は+7.7%。**

これは大切な反例である。市場の低迷が即座に業者の成約減とならない理由（成約までの期間のずれ、売却チャネル、商品価格・構成、業者と個人の売り手の違い）を追う必要がある。

**まだ未確認：** 東京23区の未売却・未契約の保有年数分布、値下げ回数、値下げ幅、仕入コホート別の粗利益、在庫評価損。2026年8月末では2026年10月の市場データに先行する点も区別する。

### 研究の結論に向けた新論点

全国・東京全体の平均市況だけから、買取再販業者の「出口渋滞」を主張できない。東京23区に絞った実企業の新しい数値でも売上・単価が強い会社がある。**問題は全社一律の売れ残りではなく、価格帯と保有物件・販売チャネルの一部で実際の販売中在庫が売れにくくなっているかどうか**。証拠の薄い「企業はみんな行き詰まる」物語に置き換えない。
