# 東京中古マンション：出口渋滞仮説を市場と企業の双方から検証する

作業版／2026-11-17。**調査対象15企業グループ（中核6・比較9）を変更しない。主眼は東京中古マンション買取再販業者の出口渋滞が実在するか、価格形成にどう波及するか。**

## 2026年11月17日追記：市況の変化が買取再販業者の実販売成約率に現れている

[スター・マイカの会社決算説明資料（2026年9月30日公表）を直接照合](PRICE_SEGMENT_EXIT_TEST.md)したところ、**同社のリノベ販売物件の月次換算成約率は、1億円未満27%、1億円以上9%（2026年6〜8月）**。8月末販売中物件は1億円未満442戸、1億円以上42戸（合計484戸、会社全地域）。2025年同時期の同指標は30%、17%であり、高価格帯の落ち込みが大きい。

また同社がREINSから計算した東京都のファミリータイプ中古マンション市場では、**2億円以上の月次成約率が2025年6〜8月5%から2026年6〜8月2%に低下**。これは**東京市場の数字**であり、上記484戸は**会社全地域の数字**。地理や物件母集団が違うため、比率を混ぜて計算しない。

さらにランドネットは2026年7月期決算で、高価格帯の区分マンションの販売価格の伸び悩みによる利益率悪化を会社自身が記している。インテリックスには販売期間短縮という反証候補もあり、**企業別・価格帯別に分断された流動性**の仮説を検証する段階に入った。

この資料は重要な企業側の証拠であるが、**東京限定の会社別未売却物件や値下げ率を証明したものではない**。

## 2026年11月17日追加 — 販売期間と買主構成を開示企業の原本で検証

[インテリックスの販売期間・施工期間・粗利益率（2024上期から2026年5月期第1四半期）およびスター・マイカの買主属性](EXIT_DURATION_BUYER_TEST.md)を追加した。

インテリックスの2024年5月期上期は販売期間139日、粗利益率9.8%。2025年5月期上期は販売期間117日、粗利益率13.4%。2026年5月期第1四半期は販売期間106日、粗利益率13.9%。これは**決済まで終了した物件の全国的な事業KPI**であり、東京23区の未売却物件の滞留期間とは異なる。

スター・マイカの1〜2億円購入者の共有名義割合は40.0%、現金購入者割合は35.6%（同社FY2025～FY2026 Q1販売実績）。**共同名義と借入額、現金購入と投機目的を同一視しない**。高価格帯の買主構成を調べる仮説の入口であり、東京だけの購買属性と推定しない。

## 1. 東京都全体の価格下落は、都区部の成約比率低下だけでは説明できない

2026年10月の東京都の中古マンション成約㎡単価は**115.58万円**で、2025年10月の**121.06万円**から約**4.5%下落**した。これは同一住戸の再販売価格比較ではなく、その月に成約した物件の平均値である。

東京都区部の成約件数は**1,836→1,343件（-26.9%）**、成約㎡単価は**135.03→129.69万円（-4.0%）**。多摩は**398→327件（-17.8%）**、平均㎡単価は**56.60→57.63万円（+1.8%）**。

東京都区部の成約件数構成比が**82.18→80.42%**へ低下しただけでなく、**都区部自身の平均成約単価も下がっている**。したがって「安い多摩の成約構成比が増えたから東京都平均が下がっただけ」という説明では足りない。

2地域の成約件数を用いた機械的な加重平均の変化を分解すると、東京都全体の平均㎡単価変化のうち**約76.8%は両地域の平均単価の変化**、**約23.2%は都区部・多摩の件数構成比の変化**に対応する。ただしこれは二地域だけの記述的な分解であり、厳密な同質物件の価格指数でも、成約個票の再加重でもない。掲載値の丸めがある。[数式・再計算方法](TOKYO_COMPOSITION_TEST.md)。

**公式一次資料：** [東日本レインズ 2026年10月月例速報サマリー](https://www.reins.or.jp/mw_202610_summary.pdf)（2026年11月10日、印刷p.3–4）。

この「都区部の取引比率だけでは説明できない」という結果は最終レポートに残す。ただし、さらに23区のどこで平均成約単価が下がったのか、成約物件の築年数・面積・立地が変化しただけではないかを検証する。

**城西の別の信号**：成約平均㎡単価**145.33万円、-8.4%**。都心3区が件数・在庫の乖離で突出する一方、城西は成約単価下落が目立つ。住宅の価格帯・広さ・築年数の構成差を必ず分離する。

**城南の反例**：在庫**+42.6%**、成約件数**-30.5%**にもかかわらず、成約㎡単価は**+7.6%**。市場の流動性低下＝同じ住戸の価格下落、という一律の推論はできない。

**城東の構成変化**：成約平均価格は**-7.7%**だが、㎡単価は**-2.9%**。平均専有面積は前年同月比**-5.0%**、平均築年数は**22.51→25.13年**と変化。安価・狭小・築古物件への成約構成の移動が平均額を動かし得る。

## 3. いまから何を検証するか（研究目的以外に広げない）

**市場で起きていること**と**買取再販業者の出口**を直結させないため、次は地区ごとに（1）物件価格帯、（2）築年・面積の成約構成、（3）新規登録→値下げ→成約の同一物件追跡データが存在するかを確認する。その上で中核6グループの東京区分中古マンションに該当する販売戸数・保有期間・借入期限・金利負担・期末在庫との時間の一致を検証する。

**売出平均価格と成約平均価格の差は値引き額ではない。** 単月の地区別平均が下がっても同一住戸が値下がりしたとは限らない。また、在庫÷成約は販売月数でも在庫回転日数でもない。

収益物件、新築分譲、オフィス、他地域の指標は背景・対照群に限定し、この研究の出口渋滞の証拠として混在させない。
