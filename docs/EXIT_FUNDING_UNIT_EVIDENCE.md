# 終盤の企業実証：インテリックス「販売戸数横ばい、必要仕入資金増加」の確認

**研究主眼を変更しない。** 東京の中古マンション価格の表層と、買取再販業者が本当に売却・資金回収で詰まっているかの差を検証する。対象15企業グループ（中核6＋比較9）は固定。企業個別の売却遅延は未立証。

## 1. 同じ戸数規模を維持するための資金が大きく増えている

| 指標 | 2025年5月期 | 2026年5月期 |
|---|---:|---:|
| リノヴェックスマンション仕入件数（2026年はリノベーション事業分野の仕入件数） | 1,075 | 1,048 |
| 仕入高 | 約244億円 | 336.84億円 |
| リノヴェックスマンション販売件数 | 1,052 | 1,043 |
| 平均販売価格 | 約2,939万円（2026年額と+30.1%から逆算した概数） | 3,824万円 |

取得物件の種類・立地構成が変化しているため、**同じ個別住戸の仕入価格が上がったと断定できない**。会社の説明では、仕入エリア戦略と価格上昇が販売単価上昇に寄与。

- 2025年5月期 [会社公式決算説明資料 p.24](https://www.intellex-hd.co.jp/ir/release/archive/pdf/di/20250711.pdf)
- 2026年5月期 [EDINET有価証券報告書（S100YYT8、本文ミラー）](https://regfis.com/reports/20260826_S100YYT8_E40879_null_010_030000_120)
- [会社公式財務指標](https://www.intellex-hd.co.jp/ir/financial/indicator/)
- [会社公式決算レビュー](https://www.intellex-hd.co.jp/ir/financial/review/)

単純な年間仕入件数−販売件数の差は2025年**+23件**、2026年**+5件**。しかし両者の公表定義に微差（リノベーション事業分野とリノヴェックスマンション）があり、**これを期末未売却在庫の増加戸数と呼んではならない**。期中のキャンセル、仕入から販売までの期またぎ、その他の物件の移動もある。

## 2. 契約済み・未引渡しの増加は「売れ残り」と別概念

2026年5月期のリノベーション事業分野契約：期首61件＋期中契約1,061件−期中引渡1,045件＝期末**77件**。増加**16件**。

これは**買主との契約が成立しているが引渡し前の物件**であり、**買主が付いていない滞留在庫ではない**。

2026年のリノヴェックスマンション販売件数1,043件とリノベーション事業分野引渡件数1,045件は母集団が異なるので取り違えない。

## 3. 資金側に現れる圧力

2026年5月期連結営業CF **-66.28億円**（2025年も-59.31億円）。短期借入金の純増加**65.26億円**。棚卸資産の増加による営業CFへのマイナス要因**76.53億円**。

これらは**仕入活動・保有資金需要の拡大を示すが、売れ残りの存在を直接証明するものではない**。東京だけの数値でもない。

## 4. 一般論に落とさないための検証命題

「中古マンション価格の上昇で、販売戸数が大きく増えなくても1戸の取得に必要な資金が増え、売却・引渡しが遅れた場合の資金負担の感応度が高まっている」

この命題はインテリックス1社については数量・資金の公表データに沿う。ただし**価格上昇を因果的な唯一の理由とは認定せず、仕入エリア・物件のグレード・用途の変化を別に扱う**。

**仮説が反証される可能性も残す。** 仕入れを資金需要に見合うよう調整でき、販売粗利を維持し、融資返済期限に余裕があれば、回転遅延や損失には至らない。インテリックスの実際の売却長期化を確認できなければ、「売り抜けられない事例」としては採用しない。

## 5. 最終稿で必ず必要な残る根拠

- 中核6社のうち同じ区分中古マンションについて、年度別仕入戸数・引渡戸数・仕入単価・売価・利益率を揃える（開示がある会社のみ）。
- 東京都に該当する部分の抽出、または抽出不可能であることの記録。
- 各社の期末未売却戸数（契約済み未引渡しと区別）、販売所要日数、価格改定・評価損が公表されているか。
- リスクを現実化させる借入満期・借換金利・担保条件の開示の有無。
- 2026年10月のREINS統計との期間差（FY2026は5月末まで）を明示し、タイミングの一致を偽装しない。

**根拠データ:** [リノヴェックスの数量・資金・契約残データ](../data/processed/renovex_unit_cost_funding.csv)。過去の[TOKYO_EXIT_EVIDENCE.md](TOKYO_EXIT_EVIDENCE.md)を市場側の別立て資料として維持する。
